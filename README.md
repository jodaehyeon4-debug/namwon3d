# 남원 3D 탐험지도

남원시 전체를 실제 공공데이터로 3D로 보는 초등 탐구용 웹앱(CesiumJS). 이 저장소는 빌드된 정적 파일(GitHub Pages 배포본)입니다.

- 앱: https://jodaehyeon4-debug.github.io/namwon3d/
- 자료 출처: 국토교통부 V-World(공공누리 제1유형, 출처 표시), 소상공인시장진흥공단 상가(상권)정보, 행정안전부 주민등록 인구, Copernicus DEM(© DLR/Airbus). 앱의 '출처' 패널 참고.
- 시설 영향·높이 등 일부 값은 교육용 추정값입니다.
